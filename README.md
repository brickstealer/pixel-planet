# 🌍 Pixel Planet

**Pixel Planet** — процедурный воксельный 3D-мир Земли, работающий непосредственно в веб-браузере на базе данных **OpenStreetMap** и графического движка **Three.js**.

Приложение выполняет потоковую загрузку реальных географических данных (контуры зданий, этажность, дорожная сеть, парки, водоёмы, природные объекты и достопримечательности) через Overpass API и в реальном времени превращает их в интерактивный воксельный мир с динамическим освещением и свободной камерой полёта.

## ✨ Особенности

- **Потоковая загрузка данных OpenStreetMap**:
  Мир разбит на географические секторы (~600×600 м). По мере перемещения игрока координаты конвертируются в геодезические (WGS84), а недостающие секторы подгружаются через Overpass API и кэшируются локально в IndexedDB.
- **Глобальный поиск и телепортация**:
  Интеграция с геокодером Nominatim позволяет ввести любой город, адрес или ориентир и мгновенно переместиться в нужную точку планеты.
- **Процедурная вокселизация окружения**:
  - Здания строятся по реальным полигонам и координатам из OSM с учётом тегов `height`, `building:levels` и типа постройки.
  - Дорожная сеть: магистрали, городские улицы и тротуары с процедурной разметкой.
  - Парки, водоёмы (реки, каналы, озёра, береговые линии) и процедурная растительность.
- **Инспекция объектов в прицеле**:
  Наведение прицела (raycasting) на любое здание отображает карточку с его названием, адресом, этажностью, высотой и списком организаций внутри (магазины, кафе, офисы).
- **Смена времени суток**:
  Поддержка режимов «День», «Закат» и «Ночь». При наступлении темноты окна зданий загораются тёплым светом благодаря кастомному шейдеру материалов.
- **Сигнальная индикация секторов**:
  Чанки, находящиеся в процессе загрузки геоданных, маркируются контрастными черно-жёлтыми полосами безопасности, сменяясь реальной застройкой по мере готовности геометрии.

## 🏛 Архитектурные архетипы

Для узнаваемых мировых объектов и ключевых классов сооружений реализованы специализированные воксельные генераторы:

| Архетип | Примеры | Особенности генерации |
|---|---|---|
| **Теле- и радиобашни** | Останкинская башня, CN Tower, Берлинская телебашня, Tokyo Skytree | Коническое расширенное основание, тонкий железобетонный ствол, панорамная гондола/ресторан, вещательный шпиль и проблесковый маяк |

## ⚡ Оптимизация и технологии

- **Greedy Meshing**:
  Вместо отрисовки отдельных кубов смежные грани вокселей одного типа объединяются в непрерывные полигоны на уровне срезов чанка. Это сокращает количество полигонов и вызовов отрисовки на 85–95%.
- **Масштабируемая дальность обзора (4–100 чанков)**:
  Радиус видимости регулируется от небольшого (для мобильных или слабых GPU) до 100 чанков (~3.2 км), с автоматической подстройкой дальности отсечения камеры (`camera.far`) и экспоненциального тумана.
- **Энергоэффективный рендеринг чанков**:
  Для статических мешей чанков отключено автоматическое обновление матриц трансформации (`matrixAutoUpdate = false`), а геометрии передаются через оптимизированные буферы `BufferGeometry`.
- **Локальное кэширование (IndexedDB)**:
  Каждый загруженный сектор сохраняется в хранилище браузера, что исключает повторные сетевые запросы при возвращении в ранее посещённые районы.
- **Адаптивный бюджет сборки**:
  Генерация геометрии чанков распределена по кадрам (дозированный бюджет в миллисекундах на кадр), что предотвращает фризы и микролаги при быстром перемещении.

## 🎮 Управление

| Клавиша / Ввод | Действие |
|---|---|
| **W, A, S, D** / **Стрелки** | Горизонтальное перемещение (вперёд, влево, назад, вправо) |
| **Мышь** | Свободный обзор (при активном захвате курсора) |
| **ЛКМ** | Захват курсора (Pointer Lock) для управления обзором |
| **Space** | Набор высоты (вверх) |
| **C** | Снижение высоты (вниз) |
| **Shift** / **E** | Форсаж (мгновенное ускорение) |
| **Колёсико мыши** | Плавная регулировка базовой скорости полёта |
| **Enter** или **/** | Фокус на строке поиска локации |
| **Esc** | Освобождение курсора / выход из строки поиска |

## 🖥 Интерфейс и HUD

- **Строка поиска**: моментальный переход к любому географическому объекту по его названию.
- **Спидометр**: индикация текущей скорости перемещения в км/ч.
- **GPS-телеметрия**: широта/долгота (WGS84), абсолютная высота, компасный курс, координаты текущего воксельного чанка и количество активных сеток на сцене.
- **Панель времени суток**: переключение между дневным, закатным и ночным освещением.
- **Слайдер дальности**: плавная настройка радиуса загрузки и отрисовки чанков.
- **Карточка объекта**: динамическая информация о здании под перекрестием прицела.

## 🚀 Быстрый старт

### Требования
- **Node.js** версии 18+
- Менеджер пакетов **pnpm** (или npm / yarn)

### Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/brickstealer/pixel-planet.git
   cd pixel-planet
   ```

2. Установите зависимости:
   ```bash
   pnpm install
   ```

3. Запустите локальный сервер разработки:
   ```bash
   pnpm run dev
   ```
   Приложение откроется по адресу `http://localhost:3000` (или `http://localhost:5173`).

4. Сборка для production:
   ```bash
   pnpm run build
   ```

5. Предварительный просмотр production-сборки:
   ```bash
   pnpm run preview
   ```

## 📡 Источники данных и API

- **[OpenStreetMap Overpass API](https://overpass-api.de/)** — поставщик векторных пространственных данных зданий, высот, дорог и инфраструктуры.
- **[Nominatim](https://nominatim.openstreetmap.org/)** — сервис прямого геокодинга для поиска городов и адресов.
- **[Three.js](https://threejs.org/)** — WebGL-рендеринг, работа с геометрией, камерой и материалами.
- Данные OpenStreetMap распространяются по лицензии [Open Data Commons Open Database License (ODbL)](https://opendatacommons.org/licenses/odbl/).
